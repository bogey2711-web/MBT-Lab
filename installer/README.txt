MBT Lab installer for Windows
=============================
Double-click MBT-Lab-Setup.cmd (keep the .ps1 file next to it). It downloads the official Electron runtime and the latest MBT Lab from
GitHub, checks both against their published SHA-256 checksums, installs to %LOCALAPPDATA%\MBT Lab and adds Desktop and Start Menu shortcuts.
Run it again at any time to reinstall the latest runtime and files. The installed app also updates its own page from GitHub each time it starts.
To remove: run "MBT-Lab-Setup.cmd uninstall" from a Command Prompt in this folder.
Windows may show "Windows protected your PC" because the files are not signed with a paid certificate: choose More info, then Run anyway.
Needs 64-bit Windows 10 or 11 and an internet connection (about 110 MB download).
