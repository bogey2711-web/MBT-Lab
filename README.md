# MBT Lab

Tank, IFV, light-tank and APC rankings, vehicle library, fact files with clickable 3D wireframes, and a duel simulator.

- **Use it in a browser or install it on your phone:** https://bogey2711-web.github.io/mbt-lab/ (on a phone, use your browser's "Add to Home Screen"). It works offline after the first visit and updates itself.
- **Windows desktop app:** checks this repository when it starts and offers to restart when a newer version has been downloaded.

## Updates

`index.html` is the whole app. `version.json` holds the build number and checksum that the desktop app checks.
